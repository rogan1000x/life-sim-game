# Day 22

## 1. 마을의 나무/돌 자원을 필드로 이전 + 풀/꽃 자원 추가
- 마을에 고정으로 나던 나무(3그루)/돌(2개)을 제거하고, 전부 동서남북 필드로 옮김.
- 새 자원 타입 추가: 풀(`grass`), 꽃(`flower`) - `ENTITY_TYPES`에 정의, `SHOP_ITEMS`에 판매 항목 추가.
- `FIELD_ZONES` 각 구역에 `resources` 목록 추가 (`monsters`와 동일한 패턴으로 `enterField()`에서 같이 스폰):
  - 북쪽 숲: 나무14, 풀10, 돌4, 꽃3 (숲 테마 - 나무/풀 위주)
  - 남쪽 평야: 풀16, 꽃10, 나무4, 돌2 (평야 테마 - 풀/꽃 위주)
  - 동쪽 산악: 돌16, 나무5, 풀4, 꽃2 (산악 테마 - 돌 위주)
  - 서쪽 해안: 꽃12, 풀8, 돌6, 나무3 (해안 테마 - 꽃/풀 위주)
- 자원도 몬스터와 똑같이 `fieldZoneId` 꼬리표로 관리돼서, 필드를 나가면 정리되고 다시 들어가면
  새로 스폰됨 (채집 후 일정 시간 뒤 리스폰되는 기존 로직은 그대로 유지).
- `GAME_CONFIG.treeCount`/`stoneCount`는 더 이상 안 쓰여서 제거 (죽은 설정 정리).
- 마을은 이제 건물/NPC/게이트/구역 입구만 남아서 더 깔끔해짐 (토끼/사슴은 요청 범위 밖이라 그대로 마을에 둠).
