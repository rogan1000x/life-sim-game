# Day 22

## 1. 마을의 나무/돌 자원을 필드로 이전 + 풀/꽃 자원 추가
- 마을에 고정으로 나던 나무(3그루)/돌(2개)을 제거하고, 전부 동서남북 필드로 옮김.
- 새 자원 타입 추가: 풀(`grass`), 꽃(`flower`) - `ENTITY_TYPES`에 정의, `SHOP_ITEMS`에 판매 항목 추가.
- `FIELD_ZONES` 각 구역에 `resources` 목록 추가 (`monsters`와 동일한 패턴으로 `enterField()`에서 같이 스폰):
  - 북쪽 숲: 나무14, 풀10, 돌4, 꽃3 (숲 테마 - 나무/풀 위주)
  - 남쪽 평야: 풀16, 꽃10, 나무4, 돌2 (평야 테마 - 풀/꽃 위주)
  - 동쪽 산악: 돌16, 나무5, 풀4, 꽃2 (산악 테마 - 돌 위주)
  - 서쪽 해안: 꽃12, 풀8, 돌6, 나무3 (해안 테마 - 꽃/풀 위주)
- 자원도 몬스터와 똑같이 `fieldZoneId` 꼬리표로 관리돼서, 필드를 나가면 정리되고 다시 들어가면
  새로 스폰됨 (채집 후 일정 시간 뒤 리스폰되는 기존 로직은 그대로 유지).
- `GAME_CONFIG.treeCount`/`stoneCount`는 더 이상 안 쓰여서 제거 (죽은 설정 정리).
- 마을은 이제 건물/NPC/게이트/구역 입구만 남아서 더 깔끔해짐 (토끼/사슴은 요청 범위 밖이라 그대로 마을에 둠).

## 2. 필드에서 몬스터가 끊기지 않고 계속 출몰하도록 변경
- 예전엔 입장 시 스폰된 물량(zone.monsters)을 다 잡으면 그걸로 끝이라, 더 사냥하려면
  한 번 나갔다 다시 들어와야 했음.
- `spawnFieldMonsterIfNeeded()`를 3.5초(`FIELD_RESPAWN_INTERVAL_MS`)마다 돌려서, 살아있는
  몬스터 수가 처음 입장 때 물량(목표치) 밑으로 떨어지면 무작위 타입으로 하나씩 보충함.
  → 헥사류 게임처럼 계속 몬스터가 나타나서 끊김 없이 사냥 가능.
- 새로 스폰되는 몬스터는 플레이어에게서 최대한 떨어진 곳(최소 300px, 10회 시도)에 생기도록 해서
  바로 옆에서 갑자기 튀어나오는 느낌을 줄임.
- 필드에서 나가면(`exitField`) 보충 타이머도 같이 제거 (다른 필드 타이머가 남아서 꼬이는 일 없게).

## 3. 마을에 집과 집 사이 길 표시 추가
- 플레이어 스폰(400,300) 근처를 허브로 삼아, 각 건물(창고/이웃집/여행자의 집/내 집/주점)과
  마을 외곽 텃밭 입구까지 흙길을 그려넣음.
- 어두운 흙색 테두리 + 밝은 흙길을 겹쳐 그려서 길 가장자리가 또렷하게 보이도록 함.
- `setDepth(-0.5)`로 다른 모든 오브젝트(나무/건물/캐릭터)보다 아래 깔리게 해서 바닥 질감처럼 보임.
- 집/던전/필드 등 실내·다른 공간에 들어가면 `setOutdoorObjectsActive()`를 통해 길도 함께 숨겨지고,
  마을로 돌아오면 다시 보임.

## 4. 마을을 중세풍으로 꾸미기
그래픽 에셋 없이, Phaser 도형(삼각형/사각형/원)만으로 중세 마을 느낌을 내봤어요.

- **집 디테일**: 밋밋한 색 네모였던 건물에 삼각 지붕, 굴뚝, 문, 창문 2개를 덧그려서 "집처럼" 보이게 함
  (`createHouse()`). 충돌 판정은 기존 사각형이 그대로 담당하고, 장식은 전부 비물리 오브젝트.
- **마을 광장**: 플레이어 스폰 지점 근처에 돌바닥 + 우물(테두리+물)을 추가.
- **가로등**: 허브~각 건물 사이 길 중간쯤에 가로등(기둥+불빛) 배치.
- **집 앞 덤불/화단**: 건물마다 입구 앞에 작은 덤불 2개씩 (초록/분홍 번갈아 배치해 획일적이지 않게).
- 전부 `this.villageDecorations` 배열에 모아서, `setOutdoorObjectsActive()`로 길(villageRoads)과
  함께 한꺼번에 숨기고 보이게 함 (집 안/던전/필드 등 다른 공간에서는 자동으로 숨겨짐).
- **참고**: 이미지 에셋을 새로 만들 수는 없어서(이 환경은 코드만 다룰 수 있음) 전부 Phaser 도형
  조합으로 구현했어요. 실제 그림/스프라이트 느낌을 원하시면 별도로 에셋을 준비해서 넣어드릴 수 있어요.
