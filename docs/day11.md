# Day 11 - NPC 상호작용 버그 수정 + Shift+클릭 대량 구매/사용

## 오늘 배운 것
- 두 물리 오브젝트가 충돌체(collider)로 서로를 막고 있을 때, 실제로 붙을 수 있는
  중심 간 최소 거리가 있다는 것. 이 최소 거리와 상호작용 판정 거리가 비슷하거나
  더 크면, 아무리 가까이 가도 조건을 통과하지 못하는 버그가 생길 수 있음
- console.log를 임시로 심어서 "어느 조건까지는 통과하고 어디서 막히는지"를
  단계적으로 확인하면, 에러 메시지가 없는 조용한 버그도 원인을 좁혀나갈 수 있다는 것
- 수량 파라미터에 기본값(quantity = 1)을 주면, 기존 호출 코드는 수정할 필요 없이
  새 기능(대량 구매/사용)을 추가할 수 있다는 것 (하위 호환 유지)
- 요청 수량보다 가진 자원(골드/아이템)이 적을 때, 전체를 거부하는 대신
  가능한 만큼만 처리하는 방식이 사용자 경험상 더 자연스럽다는 것

## 오늘 한 것

### 1단계: E키로 NPC와 대화가 안 되는 문제 확인
전날 만든 NPC 대화 시스템이 실제로는 전혀 반응하지 않는 문제를 발견.
콘솔 에러는 없었고, 조용히 아무 일도 안 일어나는 상태였음

### 2단계: 디버그 로그로 원인 좁히기
E키 입력 시점에 nearbyNpc, onDialogue 연결 여부, onShopToggle 연결 여부를
콘솔에 출력하는 임시 코드를 추가. 확인 결과 onDialogue/onShopToggle은
정상 연결되어 있었으나 nearbyNpc가 항상 null로 나옴 → 거리 판정 문제로 좁혀짐

### 3단계: 근본 원인 파악 및 수정
캐릭터와 NPC가 둘 다 80px 크기라, 서로의 충돌체 때문에 물리적으로
붙을 수 있는 최소 중심 간 거리가 이미 80에 가까운 상태였음. 그런데
상호작용 판정 조건이 "거리 < 80"이라, 아무리 붙어도 조건을 만족할 수 없었음.
판정 거리를 100으로 늘려(집의 상호작용 거리와 동일하게 맞춤) 해결.
디버그 로그는 원인 확인 후 제거함

### 4단계: Shift+클릭 대량 구매/사용 기능 추가
상점에서 아이템을 여러 개 한 번에 사고, 인�트토리에서도 여러 개를 한 번에
사용할 수 있으면 좋겠다는 아이디어로 시작. 논의 끝에 아래 방향으로 결정:
- Shift를 누른 채 클릭하면 10개, 그냥 클릭하면 1개
- 요청한 수량보다 골드나 보유 수량이 부족하면, 전체를 거부하지 않고
  가능한 만큼만 구매/사용되도록 처리 (예: 10개 살 골드가 없으면 살 수 있는 만큼만)

GameScene.js의 buyItem()/useItem()에 quantity 매개변수(기본값 1)를 추가하고,
App.js의 버튼 클릭 핸들러에서 e.shiftKey 여부로 수량을 결정하도록 구현.
버튼에 "Shift+클릭: N개" 안내 툴팁도 추가함

## 완성된 시스템 요약 (Day 11 전체)
- NPC 대화 시스템이 실제로 정상 작동함 (E키로 대사 표시, 상점 NPC는 상점도 함께 열림)
- 상점 구매와 인벤토리 아이템 사용 모두 Shift+클릭으로 10개씩 처리 가능
- 골드/보유량이 부족해도 가능한 만큼만 처리되어 사용성이 자연스러움
