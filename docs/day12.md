
# Day 12 - 시간 시스템 + 밤 몬스터 강화 + 이벤트 알림창

## 오늘 배운 것
- Phaser의 update(time, delta)에서 delta(직전 프레임 이후 실제 경과 ms)를 활용하면,
  프레임 속도와 무관하게 일정한 속도로 흐르는 게임 내 시계를 만들 수 있다는 것
- 화면 UI 오브젝트에 setScrollFactor(0)을 주면 카메라가 움직여도 화면에 고정된다는 것,
  그리고 setDepth로 오브젝트 간 그려지는 순서(위/아래)를 제어할 수 있다는 것
- add.circle/add.rectangle처럼 도형으로 만든 오브젝트는 이미지 전용 기능인
  setTint/clearTint를 쓸 수 없고, 대신 setFillStyle로 색 자체를 바꿔야 한다는 것
  (스프라이트 이미지와 도형(Shape)은 서로 다른 API를 가진 별개의 오브젝트라는 것을
  실제 에러를 통해 확인함)
- 알림(로그) 목록처럼 "추가되었다가 일정 시간 후 사라지는" UI는, 각 항목에
  고유 id를 부여하고 setTimeout으로 해당 id만 필터링해서 제거하는 방식이
  여러 알림이 동시에 쌓여도 안전하다는 것

## 오늘 한 것

### 1단계: 시간/날씨 시스템 구현
게임 속 하루(1440분)가 현실 dayLengthSeconds(기본 300초)에 맞춰 흐르도록
gameMinutes를 매 프레임 delta 기반으로 누적하는 방식으로 구현.
화면 우측 상단에 "Day N HH:MM" 형태로 표시하고, 저녁~밤에는 화면에
반투명 어두운 오버레이가 서서히 씌워지도록 구현. 실내에서는 조명이
있다는 설정으로 오버레이를 적용하지 않음. 시간/날짜는 저장 데이터에도 포함시킴

### 2단계: 밤 몬스터 강화
시간 시스템을 활용해 밤이 깊을수록(한밤중 최대) 늑대의 이동 속도와
공격력이 최대 1.5배까지 강해지도록 구현. 몬스터 체력은 건드리지 않아
밤마다 사냥 난이도가 급격히 흔들리지 않게 함. 밤에는 늑대가 붉은색으로
바뀌어 위험 상태를 시각적으로도 알 수 있게 함

### 3단계 (트러블슈팅): setTint 에러
밤에 몬스터 색을 바꾸는 코드에서 entity.clearTint is not a function 에러 발생.
원인은 나무/돌/토끼/늑대가 이미지 스프라이트가 아니라 add.circle로 만든
도형이라, 이미지 전용 기능인 setTint/clearTint 자체가 존재하지 않았기 때문.
setFillStyle로 색을 직접 바꾸는 방식으로 수정하여 해결

### 4단계: 이벤트 알림창 구현
자원/동물 채집, 몬스터 처치, 그리고 몬스터에게 사망했을 때 화면에
알림이 떴다가 3초 후 자동으로 사라지는 기능을 추가함. 알림 종류에 따라
색을 다르게 표시(획득=초록, 처치=주황, 사망=빨강)하여 한눈에 구분되게 함

GameScene.js에 onLog 콜백과 addLog() 헬퍼를 추가하고, 채집/처치/사망
지점마다 적절한 문구와 타입으로 addLog를 호출하도록 구현. App.js에는
고유 id 기반으로 알림을 추가/자동 제거하는 addLog 함수와, 게임 화면
안쪽에 겹치는 알림 목록 UI를 추가함

## 완성된 시스템 요약 (Day 12 전체)
- 게임 내 시간이 흐르고, 밤에는 화면이 어두워지며 늑대가 더 강해짐
- 몬스터 처치/자원 획득/사망 시 화면에 알림이 자동으로 뜨고 사라짐
- 도형 오브젝트와 이미지 오브젝트의 API 차이를 실제로 확인하고 대응함
