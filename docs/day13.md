# Day 13 - UI 개편 + NPC idle 모션 + 장비 시스템 + 사망 패널티

## 오늘 배운 것
- 인라인 스타일이 여러 컴포넌트에 흩어져 있을 때, 공통 색상/버튼/패널 스타일을
  상수 객체(THEME, buttonStyle, panelStyle)로 뽑아두면 톤을 한 번에 통일하고
  나중에 색상 하나만 바꿔도 전체에 반영할 수 있다는 것
- Phaser의 tween에 yoyo:true, repeat:-1을 조합하면 별도 이미지 프레임 없이도
  "제자리에서 살짝 움직이는" idle 모션을 코드만으로 표현할 수 있다는 것,
  그리고 duration에 랜덤값을 섞으면 여러 오브젝트가 기계적으로 똑같이
  움직이는 느낌을 피할 수 있다는 것
- "소모품(즉시 사용하고 사라짐)"과 "장비(장착 중일 때만 효과, 해제 가능)"는
  같은 인벤토리 아이템이라도 효과를 적용/해제하는 로직 자체가 다르다는 것,
  그리고 이 둘을 category 필드로 구분해두면 이후 로직이 훨씬 명확해진다는 것
- 장착/해제를 반복해도 스탯이 꼬이지 않으려면, "효과를 더하는 함수"와
  "효과를 빼는 함수"를 따로 만들지 않고 direction(1/-1) 파라미터로
  하나의 함수를 재사용하는 방식이 실수를 줄여준다는 것

## 오늘 한 것

### 1단계: UI 대대적 개편
지금까지 각 패널(사이드바, 상점, Admin, 대화창, 알림)마다 스타일이 제각각이었던 것을,
게임 톤(자연/농장 생활시뮬)에 맞춘 나무색+금색 팔레트로 통일함.
THEME/buttonStyle/panelStyle 상수를 App.js에 추가하고, 기존 인라인 스타일들을
이 상수를 활용하는 방식으로 교체함. 아이콘(❤️⚔️👟💰)도 항목마다 붙여 가독성을 높임

### 2단계: NPC idle 모션
NPC가 아직 걷는 프레임이 없는 에셋이라, 실제로 돌아다니게 만들기 전 단계로
제자리에서 위아래로 살짝 흔들리는 idle 모션을 tween으로 추가함.
NPC마다 흔들리는 주기를 랜덤하게 달리해서 기계적으로 보이지 않게 함.
(NPC가 실제로 돌아다니는 기능은 추후 걷기 프레임이 있는 에셋을 구한 뒤 진행 예정)

### 3단계: 장비 시스템 도입
기존에 "사용하면 즉시 영구 적용되고 소모되는" 방식이었던 상점의 도구 7종을
장착/해제 가능한 장비(equipment, weapon 슬롯)로 전환함. 포션 2종은
소모품(consumable)으로 그대로 유지. SHOP_ITEMS에 category/slot 필드를 추가하고,
GameScene.js에 equipItem/unequipItem/applyEquipEffect를 구현함.
같은 슬롯에 다른 장비를 장착하면 이전 장비 효과가 자동으로 빠지고 새 효과가 적용됨.
장비 상태는 저장 데이터에도 포함시킴. 내구도 시스템은 이 구조 위에 추후 추가 예정

### 4단계: 사망 패널티 시스템
사망 시 현재 레벨 필요 경험치의 30%를 잃고, 경험치가 모자라면 레벨이 1 내려가며
공격력/이동속도/최대체력도 소폭 감소하도록 구현(최소치 이하로는 안 내려가게 방어).
2초 후 맵 중앙에서 자동으로 부활하도록 하여, Admin 패널의 수동 부활 없이도
게임 진행이 막히지 않게 개선함. 사망/부활 과정도 이벤트 알림창에 표시됨

## 완성된 시스템 요약 (Day 13 전체)
- 전체 UI가 일관된 톤(나무색+금색)으로 통일됨
- NPC가 제자리에서 자연스럽게 숨쉬는 듯한 모션을 보임
- 상점 도구 7종이 장착/해제 가능한 장비로 전환되고, 장착 중 표시가 인벤토리에 나타남
- 사망 시 경험치/레벨/스탯이 깎이고 자동으로 부활하는 패널티 시스템이 작동함
