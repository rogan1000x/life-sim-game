# Day 16 - 용병 등급 + 승급 시험 시스템 (주점 4단계, 완료)

## 오늘 배운 것
- 여러 단계로 이루어진 등급/티어 시스템은, 각 등급에 order(순서 숫자)를 부여해두면
  "다음 등급 찾기(order+1)", "등급 비교(order 크기 비교)" 같은 로직을 훨씬 간단하게
  구현할 수 있다는 것 - 이름 문자열끼리 비교하는 것보다 훨씬 안전하고 확장하기 쉬움
- 새로운 gameConfig.js export를 추가할 때마다 GameScene.js/App.js의 import 문에
  그 이름을 추가하는 걸 반복적으로 빠뜨렸다는 것을 다시 한번 확인함 - 이제는 새 데이터를
  추가하는 작업의 마지막 단계로 "import 문 확인"을 습관화할 필요가 있음

## 오늘 한 것

### 1단계: 용병 등급 시스템 설계 및 구현
주점(용병 길드) 마지막 단계로, 리나에게 직접 승급 시험을 보는 방식의 등급 시스템을
구현함. RANK_TIERS에 초급/중급/고급/특급 4단계를 정의하고, 각 등급마다 승급에 필요한
레벨, 완료 퀘스트 수, 시험비(골드)를 설정함. GameScene에 rank(현재 등급)와
questsCompletedCount(누적 퀘스트 완료 횟수) 상태를 추가하고, turnInQuest()에서
완료할 때마다 이 횟수가 누적되도록 연결함

### 2단계: 등급별 퀘스트 잠금
기존 퀘스트 5개에 minRank: 'bronze'를 부여해 누구나 받을 수 있게 유지하고, 중급/고급
전용 상위 난이도 퀘스트 2개(늑대 무리 소탕, 대규모 늑대 토벌)를 추가함. 등급이
낮으면 주점 퀘스트 목록에서 🔒 표시와 함께 잠긴 상태로 보이도록 처리

### 3단계: 승급 시험 구현
takeExam() 함수가 다음 등급의 조건(레벨/완료 퀘스트 수/시험비)을 순서대로 확인하고,
하나라도 부족하면 어떤 조건이 부족한지 알림으로 알려주도록 구현. 조건을 모두
만족하면 시험비를 지불하고 즉시 승급됨. 주점 UI에 현재 등급, 다음 등급 조건,
승급 시험 버튼을 추가함

### 4단계 (트러블슈팅): import 누락 반복
RANK_TIERS를 gameConfig.js에 추가한 뒤, GameScene.js의 import 문에 추가하는 걸
또 빠뜨려 'RANK_TIERS' is not defined 에러가 발생함. 이전에도 여러 차례 반복된
패턴이라, 앞으로 새 데이터를 gameConfig.js에 추가할 때는 관련된 모든 파일의
import 문을 함께 확인하는 것을 원칙으로 삼기로 함

## 완성된 시스템 요약 (Day 16 전체)
- 용병 등급(초급/중급/고급/특급)이 생기고, 사이드바에 현재 등급이 표시됨
- 리나에게 승급 시험을 볼 수 있고, 조건 부족 시 무엇이 부족한지 알려줌
- 상위 등급 전용 퀘스트가 낮은 등급에서는 잠겨서 안 보이거나 잠금 표시됨
- 이것으로 주점(용병 길드) 시스템 1~4단계(건물/휴식/음식, 퀘스트, 동료 고용, 등급)가 모두 완료됨
