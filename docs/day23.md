# Day 23

## 1. 마을 이동 편의성 개선
- **대각선 이동 속도 버그 수정**: X/Y 속도를 각각 moveSpeed로 넣어서 대각선이 약 1.4배 빨랐음.
  방향 벡터를 정규화(×1/√2)해서 어느 방향이든 속도가 같게 함 (`handleMovement`).
- **충돌 박스 축소** (보이는 크기는 그대로, 부딪히는 판정만 작게):
  - 플레이어: 전신 80x80 → 발 쪽 60x50 (`setSize(12,10)` + `setOffset(2,6)`, 원본 픽셀 기준)
  - 건물: 좌우 8px / 위 14px / 아래 6px씩 깎음 (`shrinkStaticBody`)
  - NPC(마을 3명 + 주점 리나): 하체 40x40만 충돌
  - 게이트는 그대로 (가까이 가서 G키 누르는 대상이라 유지)
- **참고**: 플레이어 판정이 작아졌으니 몬스터 접촉 피해도 약간 덜 받음. 너무 쉬워지면
  `setSize`/`setOffset` 값을 키우면 됨. 실제 화면 확인은 못 해서 체감에 따라 조정 필요.
