# Day 19 - 동료 이름/개성/특성 확장

## 오늘 배운 것
- 데이터의 키(id) 값을 바꾸면, 기존에 그 키를 참조하고 있던 저장 데이터(localStorage 등)는
  자동으로 갱신되지 않기 때문에 "예전엔 있었지만 지금은 없는 id"를 참조하다 생기는
  undefined 에러가 날 수 있다는 것. 이런 경우 불러오기 시점에 예전 id를 새 id로
  매핑해주는 마이그레이션 코드를 추가하면, 기존 플레이 데이터를 잃지 않고 안전하게
  구조를 바꿀 수 있다는 것
- 어떤 값을 참조하는 함수라도, 데이터에 없는 값이 들어올 가능성이 있다면 기본값으로
  방어(`|| { name: '동료' }` 같은 형태)해두면, 예상 못한 상황에서도 최소한 에러 없이
  기능이 동작하게 만들 수 있다는 것
- 같은 스프라이트 이미지라도 setTint로 색조를 다르게 입히면, 새 그림을 구하기 전까지
  최소한의 시각적 구분을 만들 수 있다는 것

## 오늘 한 것

### 1단계: 동료 4명으로 확장 (이름/개성/특성 부여)
기존에 "떠돌이 동료" 하나뿐이던 동료를 로이(성실한 여행자, 밸런스형)/미라(대담한
전직 용병, 공격형)/세인(신중한 은둔 학자, 방어형)/파이(쾌활한 방랑자, 성장형)
4명으로 확장함. 각자 능력치 성향을 다르게 주고, 개성 있는 특성을 하나씩 부여함:
- 미라: critBonus - 20% 확률로 기본 공격에 추가 피해(2배)가 터짐
- 세인: damageReduction - 몬스터에게 받는 피해를 25% 감소시킴
- 파이: expBonus - 획득하는 경험치가 1.5배로 늘어남 (성장이 빠름)

고용 시 각자 다른 고용 대사(hireLine)가 뜨도록 하고, 새 전용 그림을 구하기 전까지는
같은 스프라이트에 서로 다른 색조(tint)를 입혀 최소한의 외형 구분을 만듦

### 2단계 (트러블슈팅): 예전 저장 데이터의 'traveler' id 참조 에러
동료 id를 traveler에서 roy/mira/sein/pie로 바꾸면서, 예전에 이미 동료를 고용해둔
저장 데이터에는 여전히 hiredCompanionId: 'traveler'가 남아있어 COMPANION_TYPES에서
찾지 못해 undefined.name을 읽으려다 에러가 발생함. 저장 데이터를 불러오는 시점에
'traveler'를 'roy'로 자동 변환하는 마이그레이션 코드를 추가하고, dismissCompanion()도
데이터를 못 찾는 경우 기본 이름으로 안전하게 처리하도록 방어 코드를 추가해 해결함

### 3단계: ESC 메뉴 (키 설명 / 옵션 / 게임 종료) 구현
ESC키를 누르면 게임이 완전히 일시정지되면서(시간도 안 흐르고 몬스터도 안 움직임)
키 설명, 소리/밝기 옵션, 게임 종료를 한 화면에 모은 메뉴가 뜨도록 구현함.
GameScene에 isPaused 플래그를 추가해 update() 맨 위에서 조기 종료시키고,
setPaused/setSoundVolume/setBrightness 함수로 App.js의 옵션 UI와 연동함.
밝기는 별도의 brightnessOverlay(검은 사각형 + 알파값)로 표현해 기존 밤 효과
오버레이와 독립적으로 작동하도록 분리함. 게임 종료 버튼은 브라우저 보안 정책상
window.close()가 항상 통하지 않을 수 있어, 안 닫힐 경우 안내 문구를 보여주도록 처리함

### 4단계: 나머지 5개 직업 패시브 스킬 채우기
전사와 동일한 패턴(처음부터 배울 수 있는 것 2개 + 레벨3 해금 1개 + 처치15마리
해금 1개 + 레벨7 해금 1개, 각 최대 5레벨)으로 궁수/마법사/성직자/도적/소환사의
패시브 스킬을 전부 채움. 직업별 성향에 맞춰 효과를 배분함(궁수-속도/치명타,
마법사-공격력/생존, 성직자-체력/방어력, 도적-치명타/속도, 소환사-체력/공격력).
CLASS_SKILLS 데이터만 채우는 작업이라, 이미 범용으로 만들어둔 스킬 해금/강화
로직(upgradeSkill, isSkillUnlocked)이 코드 변경 없이 그대로 작동함

### 5단계: 동료 성장 시스템 확인
"동료도 경험치를 얻고 성장하게 해달라"는 요청이 있었으나, 확인 결과 지난
GameScene.js 전체 재정리 시점에 이미 gainCompanionExp()로 구현되어 있었음
(전투 참여 시 경험치 획득, 레벨업 시 최대체력 +10 및 공격력 자동 상승,
주점 UI에 레벨/경험치 표시, 저장/불러오기 유지). 추가 개선 여부를 확인했으나
현재 방식으로 충분하다는 판단 하에 다음 작업으로 넘어감

### 6단계: 새 생물 3종 및 퀘스트 3종 추가
사슴(순한 동물, 토끼보다 비싼 사냥감), 고블린(늑대보다 약한 초반용 몬스터),
도적(늑대보다 강한 고급 몬스터)을 ENTITY_TYPES에 추가함. 기존 시스템이 카테고리
(resource/passive_animal/hostile_monster) 기반으로 완전히 범용화되어 있어서,
GameScene.js는 스폰 루프 한 줄씩만 추가하면 될 정도로 코드 변경이 거의 없었음.
상점 판매 아이템과 함께, 사슴 사냥/고블린 소탕/도적 소탕(중급 등급 전용) 퀘스트
3개를 QUEST_TEMPLATES에 추가함

## 완성된 시스템 요약 (Day 19 전체, 갱신)
- 동료가 이름, 개성 설명, 색조로 구분되는 4명으로 늘어남
- 동료마다 고유한 전투 특성(치명타 확률/피해 감소/경험치 배율)이 실제로 작동함
- 예전 저장 데이터도 에러 없이 자동으로 새 구조에 맞춰 이어짐
- ESC 메뉴로 조작키 안내, 소리/밝기 조절, 게임 종료가 가능해짐
- 6개 직업 모두 패시브 스킬 5개씩(해금 조건 포함)을 완비함
- 동료 성장 시스템이 이미 정상 작동 중임을 재확인함
- 사슴/고블린/도적 3종 생물과 관련 퀘스트 3개가 추가되어 콘텐츠가 풍부해짐
